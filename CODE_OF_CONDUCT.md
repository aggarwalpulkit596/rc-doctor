# Code of conduct

rc-doctor follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), the code of conduct RevenueCat's SDK repositories use too. It applies to issues, pull requests, discussions and anywhere else the project meets people.

In short: be welcoming and respectful, assume good intent, give and take feedback gracefully, and keep harassment, insults and personal attacks out of the project.

To report behavior that breaks it, contact the maintainer, [@aggarwalpulkit596](https://github.com/aggarwalpulkit596), privately through GitHub. Reports are handled confidentially.
